The field, measured.

Fathom is a browser console for spatial, radio and acoustic observation. Connect supported inputs, inspect the measurements, and keep a local record of what the sensors saw.

From input to observation.

The console starts in standby. Connect a sensor, select a recording, or explicitly open the labelled simulation. Spatial frames share the same FTHM binary format across the bridge, simulator and phone scanner. No generated scene is presented as a live scan.

Object tracks enter the log after eight confirmed observations. A configurable proximity rule reports when a confirmed track enters your chosen radius. This is a distance notice, not a threat classifier.

Capture, review, replay.

Record point-cloud frames to a local .fthm file, replay them at their recorded pace, or export the observation log as JSON. A SHA-256 checksum accompanies each recording. It supports file-integrity comparisons; it does not establish the origin or authenticity of a measurement.

Connect your hardware.

For direct USB CSI, open Fathom in desktop Chrome or Edge, select Wi-Fi, choose USB ESP32, and select the serial port. The board must already run compatible esp-csi firmware at 921600 baud.

For a LiDAR on your local network, run the bridge beside the device:

cd bridge
uv sync --extra csi
uv run fathom-bridge --source udp

A console hosted over HTTPS needs a trusted WSS bridge endpoint. Configure your bridge certificate and the allowed console origin:

uv run fathom-bridge --source udp   --cert certificate.pem --key private-key.pem   --allow-origin https://abdelhakim-baalla.github.io

Certificates must be valid for the hostname used by the browser. Keep the bridge on a trusted local network. Origin filtering is not user authentication. For local phone development, the repository also provides an HTTPS dev server with a bridge proxy.

Know the limits.

Can an ordinary router scan a room or see through walls?

Not with this application. Fathom needs hardware that exposes Wi-Fi channel-state measurements. One CSI link can indicate motion-related channel changes; it cannot reconstruct a room, count or locate people, or create a through-wall image.

Has every hardware path been field-tested?

No. Protocol, geometry and relay behavior have automated tests, but physical LiDAR, ESP32 and phone validation remains outstanding. The project is an engineering preview, not a certified safety or security system.

Does Fathom upload microphone or sensor data?

The console processes inputs on your device. A connected bridge carries frames to its connected clients; the static website does not receive those streams. You choose when to export files. Interface sounds are separate cues, not recordings of detected objects.

Is Fathom affiliated with an agency?

No. Fathom is an independent project by Abdelhakim Baalla. Its identity is original and does not represent a government, military or law-enforcement agency.
