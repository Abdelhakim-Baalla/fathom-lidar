# FATHOM / FIELD SYSTEMS

Fathom means both measuring depth and making sense of complex information. It suits a sensor console that turns range measurements into spatial understanding. FIELD SYSTEMS gives the name an equipment-oriented, professional register without claiming military or public-agency affiliation.

## Mark

The mark contains three staggered, open contour bands on a 24-unit square. Each contour rises vertically, turns through a short 45-degree chamfer, and opens toward the right. Their repeated bend suggests nested apertures, depth slices, and the three horizontal levels of an F. It deliberately avoids crosshairs, weapons, shields, ranks, flags, official seals, and agency insignia.

The first band occupies x/y 3–21. Each following contour begins six units inward. Bands are three units thick and gaps are three units wide. The three-cut silhouette survives at 24px; use 24px or larger when possible, and the favicon version for browser tabs. Keep at least 3 units of clear space outside the mark. Do not rotate or stretch it.

## Files and use

- `fathom-mark.svg`: orange mark with transparent background.
- `fathom-mark-mono.svg`: `currentColor` mark for inline use.
- `favicon.svg`: orange mark inset in a graphite rounded square.
- `fathom-wordmark.svg`: custom outlined geometric FATHOM lettering, no external font.
- `fathom-lockup.svg`: horizontal mark and outlined wordmark; FIELD SYSTEMS descriptor uses system monospace. Use separate HTML descriptor text if exact layout control is needed.
- `fathom-icons.svg`: 20-symbol SVG sprite. Example: `<svg aria-hidden="true"><use href="/fathom-icons.svg#icon-scan" /></svg>`.
- `icons/*.svg`: standalone equivalents. Every icon is on a 24px grid with a 1.5px stroke, square ends, and angular joins. In inline SVG, inherit the surrounding text color. Decorative icons should have `aria-hidden="true"`; label their parent buttons.
- `tokens.json`: palette, mark geometry, and icon manifest for code integration.
- `preview.html`: standalone identity specimen.

Palette: graphite #101114, signal orange #f48142, white #f4f4f5, neutral #a4a5a8. Orange identifies active controls and important readings; neutral supports secondary system information. Reserve brighter warning/error colors for actual status, not brand decoration.
