When WebGL cannot start

Fathom automatically opens a sampled Canvas 2D point-cloud view. Drag to orbit, scroll to zoom and use Chase, Plan or Side. The CPU label identifies this renderer. The display holds up to 60,000 sampled returns; recording and the range image continue receiving the full input.

Try GPU requests a new WebGL 2 context. If the browser still refuses it, the software view remains active. Check graphics acceleration in browser settings and the graphics driver. A device with a working GPU context uses the full-density renderer. Losing that context switches to software without restarting acquisition.

A phone and an ordinary router

A microphone can provide real acoustic measurements after permission is granted. A phone camera alone does not provide WebXR depth. The browser must expose the required immersive AR and depth features; the phone scan option is unavailable otherwise.

A normal Huawei or other router does not expose Wi-Fi CSI through this web app. ESP32 CSI acquisition requires compatible firmware and either USB serial access or the Python bridge. The software does not infer hidden people, identify individuals, or reconstruct a room from router access.

Validate a radio link

Allow five seconds of quiet input for baseline calibration. Recalibrate after moving the transmitter or receiver. A packet gap or a channel-width change resets the detector. Distinguish Waiting, Calibrating, Quiet, Motion and Stale Input before interpreting the signal. These states describe channel measurements, not security classifications.

Connect real spatial input

The bridge decodes Velodyne VLP-16 UDP packets and relays FTHM frames. Protocol tests and synthetic fixtures validate the software path. Physical LiDAR and ESP32 trials have not been completed. An open socket does not establish measurement accuracy: verify timestamps, dimensions and known test movements against your actual device.
