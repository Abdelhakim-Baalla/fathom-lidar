LiDAR Point Cloud Viewer & Simulator

Explore how a spinning LiDAR measures a scene. Fathom turns sensor frames into an interactive point cloud with range rings, return intensity, object tracks and recording controls.

Start without hardware

Open the console and choose Explore simulation. The city drive computes returns by casting rays from a modelled spinning sensor. Beam count, rotation rate, range noise, dropout and weather affect the measurements. The source is explicitly labelled as a simulation.

Use Chase, Plan or Side to change the view. Drag the point cloud to orbit and scroll to zoom. The arrow keys also orbit; keys 1, 2 and 3 select the camera views. Space pauses or resumes the active scan when a form control is not focused.

Read the point cloud

Range colouring separates near and far returns. Intensity shows return strength and highlights retroreflectors. Height colours distinguish road-level points from elevated structures. Channel colouring alternates beam rings. Ground truth is available only in simulation, where the scene classes are known.

Increasing the revolutions held leaves more past points visible. Moving objects can leave trails because the display accumulates measurements over time. These trails are history, not additional objects.

Object tracks and proximity

The perception pipeline removes ground, clusters returns and tracks candidate objects between frames. Object classes are heuristic. Confirmed tracks enter the observation log after eight observations. Select a log row to inspect the corresponding track.

Enable Proximity and set a radius to report confirmed tracks that enter that distance. An orange notice and optional warning cue accompany the event. Simulation and replay remain labelled. Proximity measures distance; it does not classify a person or object as a threat.

Connect a LiDAR

The Python bridge supports Velodyne VLP-16 UDP packets and the FTHM frame protocol. Run uv run fathom-bridge --source udp from the bridge directory, then choose Connected device in the console. An HTTPS console requires a trusted WSS endpoint. See the hardware setup instructions for certificate and origin configuration.

The code has protocol tests, but physical-device validation is still outstanding. Check dimensions, timestamps and packet rates against your own device before interpreting a capture.

Record and review

Record saves point-cloud frames into a local .fthm file. Stop and seal closes the recording and computes its SHA-256 checksum. Reopen it through Recording file and scrub the timeline. Export log produces a separate JSON observation report. A checksum supports integrity comparisons; it does not certify where a recording came from.
